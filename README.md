# 🏏 T20 World Cup Cricket Data Analysis

This project analyzes data from the **2022 T20 Cricket World Cup** to identify a data-driven Dream 11 team. The analysis involves web scraping (via Bright Data) from **ESPNcricinfo**, followed by data cleaning and transformation using Python (Pandas, Jupyter Notebook). Insights are visualized using **Matplotlib** and **Seaborn**, and a **Power BI** dashboard is created for interactive data exploration.

## Features:
- **🌐 Web Scraping**: Data is collected from ESPNcricinfo using Bright Data for comprehensive coverage of player statistics.
- **🧹 Data Cleaning**: The dataset is cleaned and transformed using Pandas to ensure accuracy and consistency.
- **📊 Data Visualization**: Insights are visualized using Matplotlib and Seaborn to highlight key trends and patterns.
- **📈 Power BI Dashboard**: An interactive dashboard is created in Power BI for dynamic data exploration and presentation.

## Technologies Used:
- **🐍 Python**: For data manipulation and analysis.
- **📚 Pandas**: For data cleaning and transformation.
- **📓 Jupyter Notebook**: For interactive coding and documentation.
- **📉 Matplotlib**: For creating static visualizations.
- **🎨 Seaborn**: For enhanced statistical data visualization.
- **📊 Power BI**: For creating interactive dashboards.

## How to Run:
1. **📥 Clone** the repository to your local machine.
2. **📦 Install** the required packages using `pip install -r requirements.txt`.
3. **📓 Open** the Jupyter Notebook to explore the analysis and visualizations.
4. **📊 Access** the Power BI dashboard for interactive data exploration.

## Insights:
- The project aims to identify the best combination of players for a Dream 11 team based on performance metrics and statistical analysis.
