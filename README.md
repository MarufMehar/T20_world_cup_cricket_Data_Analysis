# T20_world_cup_cricket_Data_Analysis
This project analyzes data from the 2022 T20 Cricket World Cup to identify a data-driven Dream 11 team. Using web scraping (via Bright Data) from ESPNcricinfo, the dataset was cleaned and transformed with Python (Pandas, Jupyter Notebook). Insights were visualized using Matplotlib and Seaborn, and a Power BI dashboard was created .
